# 新增 UnitRemovedEvent(async/await 版)+ StatsComponent 清理

## 新文件 csproj/src/Events/UnitRemovedEvent.cs

```csharp
using System.Threading.Tasks;
using StdLib;

public struct UnitRemovedEventData
{
    public unit u;
}

public class UnitRemovedEvent : EventBase<UnitRemovedEventData>
{
    public const int RemoveDelayMs = 90000;

    // 死亡等待中的单位 -> 令牌;令牌失配 = 等待已失效(提前 Remove、二次死亡或 handle 复用)
    private readonly Dictionary<unit, int> _pending = new();
    private int _nextToken = 0;

    public static UnitRemovedEvent _instance { get; private set; } = null!;
    public static UnitRemovedEvent Instance
    {
        get { _instance ??= new UnitRemovedEvent(); return _instance; }
    }

    public UnitRemovedEvent()
    {
        var t = CreateTrigger();
        TriggerRegisterAnyUnitEventBJ(t, EVENT_PLAYER_UNIT_DEATH);
        TriggerAddAction(t, () => { StartDeathRemoval(GetTriggerUnit()); });
    }

    private async void StartDeathRemoval(unit u)
    {
        _nextToken += 1;
        var token = _nextToken;
        _pending[u] = token;
        await Task.Delay(RemoveDelayMs);
        var valid = _pending.TryGetValue(u, out var cur);
        if (!valid) return;
        if (cur != token) return;
        _pending.Remove(u);
        ResponseCall(new UnitRemovedEventData { u = u });
    }

    /// <summary>统一移除入口。移除单位必须走这里;直接调 native RemoveUnit 不会触发本事件。</summary>
    public static void Remove(unit u)
    {
        if (u == null) return;
        Instance._pending.Remove(u);
        RemoveUnit(u);
        Instance.ResponseCall(new UnitRemovedEventData { u = u });
    }
}
```

要点:
- 全玩家死亡注册用 `TriggerRegisterAnyUnitEventBJ`(SpellEvent.cs 同款)。
- 90 秒延迟用 `await Task.Delay`(async void 方法体由转译器自动包进协程,从触发器回调调用成立)。协程不可取消,防双发靠令牌失配静默退出。
- 令牌语义(已论证无泄漏):`_pending` 每个条目唯一属主是令牌匹配的协程;`!valid` = 条目已被 Remove() 清掉,`cur != token` = 条目已易主给新等待者(它自己会清)。老协程两种情况都不许删,删了反而弄丢新属主的事件。`_pending.Remove` 先于 `ResponseCall`,监听者抛异常不影响清理。

## StatsComponent.cs 两处小改

Init() 里追加 `UnitRemovedEvent.Instance.Register(OnUnitRemoved);`,新增:

```csharp
private static void OnUnitRemoved(UnitRemovedEventData data)
{
    Components.Remove(data.u);
}
```

## 已知限制(记录,不处理)

- 句柄复用:死亡后 90s 内 handle 复用给新单位时,失配协程可能误删新单位条目(概率低,现有同类机制未防)。
- 同一单位调两次 `Remove(u)` 会发两次事件;当前监听者(Components.Remove)幂等,无害。将来出现非幂等监听者时在事件层加已移除集合。
- 旁路 native RemoveUnit 不触发事件,靠约定(当前 src 无调用点)。
- Selection.cs 手写玩家循环可换 BJ 一行,不在本次范围。
